## Phase 0 — 저장소와 데이터 모델

NIMBYRAILTABLE의 기존 `ALL_TRAINS`, `STATION_DB`, `_stnCoord`, 지연·운행 도메인 모듈을 RailLink의 `RailData` 어댑터로 계속 사용한다. 여기에 최신 저장 파일에서 추출한 지도 데이터 `NIMBI_LATEST_MAP`을 별도 필드로 연결했다.

원본 저장 파일에서 확인한 선언값은 선로점 70,351개, 역 1,375개, 열차 1,645개, 노선 360개다. 현재 검증된 스키마로 추출된 값은 선로점 64,963개, 한반도 범위 좌표점 62,802개, 선로 연결 53,555개, 역 1,334개다.

## Phase 1 — 지도 데이터 계층

- `buildRailNetwork`는 원본 저장 파일의 실제 선로 형상과 역 좌표를 우선 사용한다.
- 원본 지도 역 이름이 기존 승차권 시간표 역과 일치하면 예매·시간표 기능을 연결한다.
- 원본에만 있는 역은 지도와 역 상세를 제공하고, 시간표가 없는 검색 버튼은 비활성화한다.
- `trainGeoPath`, `stationServices`, `stationTimetable`은 검증된 기존 시간표를 사용한다.
- `estimatedTrainSnapshot`, `snapshotCoordinate`는 기존 운행 계산을 재사용해 열차 위치를 추정한다.

원본 선로와 시간표 열차 위치는 서로 다른 데이터 계층이다. 화면에도 원본 저장 파일 선로와 “시간표 기반 위치 추정”을 구분해 표시한다.

## Phase 2 — OpenStreetMap 지도

Web Mercator 투영과 OSM 표준 타일 위에 실제 가상 선로 53,555개 연결을 SVG 단일 경로로 렌더링한다. 드래그, 휠·버튼 확대/축소, 전국 보기, 역 선택과 키보드 접근을 지원한다. OSM 배경을 끈 상태에서도 원본 선로 오버레이는 동작한다. 화면 밖 선로 경로는 렌더링 전에 제외한다.

## Phase 3 — 화면과 기존 기능 연결

- 더보기 → 철도 노선도·열차 지도
- 철도 지도에서 원본 역, 열차번호, 시간표 노선 검색
- 원본 지도 역 상세와 좌표 표시
- 시간표 연결 역에서 출발 열차 검색과 역 시간표
- 조회 결과·승차권·운행 정보에서 선택 열차 지도
- 선로, 역명, 운행 중 열차, 선택 열차 강조, OSM 배경, 등급 필터 설정

## 검증과 재생성

```sh
python3 tools/extract_nimbyrails5_map.py \
  "Mysterious Enterprise.nimbyrails5" data/nimbi_latest_map.js
```

단위 테스트는 원본 선로 선택, 원본 좌표 우선순위, 원본 전용 역, 기존 시간표 fallback, 자정 통과 위치와 Web Mercator 변환을 확인한다. 모바일 Chromium 검증은 원본 SVG 선로, 출처 문구, 역 상세·시간표, 열차 위치, 설정 저장과 320·390·600px 반응형 레이아웃을 확인한다.

## 남은 데이터 제약

저장 파일의 열차·노선 엔티티 개수는 확인했지만, 열차와 노선 레코드를 시간표에 안전하게 연결하는 전체 스키마는 아직 검증하지 않았다. 따라서 저장 파일 열차를 기존 시간표에 임의 병합하지 않는다. 현재 열차 경로와 위치는 기존 NIMBYRAILTABLE 시간표 데이터이며 실시간 GPS가 아니다.

## 2026-11-03 열차 지도 UI 및 운행 판정 개편

열차 지도는 별도 요약 페이지를 제거하고 하나의 전체 화면 지도 인스턴스에서 전체 열차와 선택 열차 모드를 전환한다. 상단 헤더·검색·설정을 지도 위에 두고, 열차 선택 정보는 축소·중간·전체 상태를 갖는 하단 바텀시트에 표시한다. 열차를 연속 선택하거나 모드를 바꿔도 지도 DOM과 사용자가 이동한 중심·확대 수준을 유지한다.

KST 운행일은 `railServiceDate`에서 오전 4시를 경계로 계산한다. 지도에서 열차 인스턴스를 고를 때 전날 운행일, 현재 달력일, 직전 운행일 후보를 함께 계산하고 운행 중 인스턴스를 우선한다. 따라서 자정 이후와 04시 이후에도 실제 도착 전인 전날 출발 열차가 새 운행으로 바뀌지 않는다. 시간표 파서는 `24:30`, `25:38`, `28:00` 같은 확장 시각도 같은 운행일의 누적 분으로 처리한다.

선택 열차 경로는 정차역 좌표를 선으로 잇지 않는다. 원본 저장 파일 선로 좌표를 그래프로 구성하고 각 시간표 경유점을 그래프에 매칭해 A*로 선로 좌표열을 복원한다. 원본 추출 과정에서 그래프 점이 누락된 곳은 200m 이내의 선로 끝점만 근접 연결하며 이 사용 여부를 경로 상태에 기록한다. 경로를 찾지 못한 역간 구간은 직선으로 메우지 않고 표시에서 제외한다. 열차 예상 위치도 현재 시간표 구간의 복원된 선로 거리 위에서 보간한다.

원본 저장 파일에는 선로별 일반철도·도시철도 서비스 유형이 없다. 역 이름이나 전철화 여부로 임의 분류하지 않고, 일반열차 시간표에 연결되지 않은 원본 전용 역을 기본 지도에서 숨긴다. KTX·ITX 등 일반열차가 이용하는 공용 선로를 보존하기 위해 선로 자체는 현재 단계에서 서비스 유형으로 삭제하지 않았다. 저장 파일의 열차·노선 엔티티 스키마가 검증되기 전까지 선로 유형 필터 완료로 보고하지 않는다.
