# NIMBIRAIL TICKET 철도 지도 구현 보고

## 기준 데이터

열차 지도는 NIMBYRAILTABLE `js/nimbi_rail.js`의 원본 `MAP_LINES`를 일반철도 기준망으로 사용한다. `METRO_LINES`와 일반철도·전철이 섞인 상세 저장 파일 선로는 RailLink 실행 묶음에서 로드하지 않는다.

`NIMBYRAILTABLE/tools/build_mainline_map.mjs`는 `MAP_LINES`의 노선·경로·역 순서를 읽고 `STATION_DB`의 실제 위경도를 결합해 `data/nimbi_mainline_map.js`를 생성한다. 현재 생성 결과는 30개 노선 정의, 56개 경로, 409개 역, 465개 인접역 구간이며 약 33KB다.

```sh
cd NIMBYRAILTABLE
node tools/build_mainline_map.mjs
```

## 경로 모델

기본 지도는 각 `MAP_LINES` 경로의 역 좌표를 순서대로 잇는다. 저장 파일의 수만 개 선로점을 렌더링하지 않으므로 역간 선형과 분기 구조는 유지하면서 불필요한 세부 좌표를 제거한다.

선택 열차는 시간표 경유지를 원본 노선도 역에 연결하고, 인접역 그래프에서 노선명이 일치하는 간선을 우선해 경로를 만든다. 시간표에만 있는 중간 지점은 앞뒤 원본 역 구간에 포함한다. 원본 노선 정의가 서로 단절된 예외에도 해당 역 사이를 한 구간으로 연결해 경로 일부가 사라지지 않게 한다. 열차 예상 위치는 완성된 역간 경로의 거리에 따라 보간한다.

현재 문제 사례 검증값은 다음과 같다.

| 열차 | 경로점 | 누락 구간 | 단순 보완 구간 |
|---|---:|---:|---:|
| ITX-청춘 2038 | 39 | 0 | 0 |
| KTX-산천 8039 | 43 | 0 | 0 |
| ITX-새마을 1142 | 32 | 0 | 0 |
| ITX-새마을 1198 | 38 | 0 | 0 |

## 지도 화면

Web Mercator 투영과 OpenStreetMap 타일 위에 일반철도 노선도와 시간표 기준 열차 위치를 표시한다. 전체 열차와 선택 열차는 같은 지도 인스턴스를 사용하며 드래그, 확대·축소, 전국 보기, 검색, 역 선택, 하단 정보창을 지원한다.

KST 운행일은 오전 4시를 경계로 계산한다. 자정 이후와 04시 이후에도 도착 전인 전날 출발 열차를 같은 운행으로 유지하며 `24:30`, `25:38`, `28:00` 같은 확장 시각도 처리한다. 지도 위치는 실시간 GPS가 아닌 시간표 기준 예상값이다.

## 검증

`npm test`는 원본 일반철도 데이터 선택, 상세 혼합 선로 제외, 역간 경로 연속성, 네 문제 열차의 전체 경로, 자정 운행, 위치 보간과 Web Mercator 변환을 확인한다. `python3 tools/verify-rail-map.py`는 모바일 Chromium에서 전체 지도, 열차 검색, 선택 경로, 지도 인스턴스 유지와 설정 저장을 확인한다.
