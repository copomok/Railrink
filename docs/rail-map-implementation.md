# NIMBIRAIL TICKET 철도 지도 구현 보고

## 입력 자료 확인

- 요청에 적힌 최신 원본 맵은 `https://share.nimbyrails.com/O83t7wcn_KgDzSDvqfp0RA`이다.
- 2026-11-02 구현 환경에서 공유 페이지는 HTTP 403을 반환했다. 원본 선로 GeoJSON이나 게임 저장 파일을 확인할 수 없었으므로 기존 데이터에 합치지 않았다.
- 첨부 ZIP에는 철도 지도 상세 개발 문서와 지도 UI 9화면 대신 관광상품 확장 문서와 관광상품 UI 5화면이 들어 있었다. 이번 구현은 메시지의 기능 요구와 별도로 첨부된 지도 UI 4화면을 기준으로 진행했다.

## Phase 0 — 저장소와 데이터 모델

NIMBYRAILTABLE의 `ALL_TRAINS`, `STATION_DB`, `_stnCoord`, 지연/운행 도메인 모듈을 RailLink의 기존 `RailData` 어댑터로 재사용한다. 현재 앱 런타임에서 확인되는 원본은 열차 1,907개, 전체 역 DB 좌표 1,517개이며, 이 가운데 열차 운행 순서에 실제로 등장하는 좌표역 415개가 지도 토폴로지를 구성한다. `sourceId`가 있는 역은 그 ID를 역 상세에 유지한다.

기존 NIMBYRAILTABLE의 `MAP_LINES`는 사람이 보기 좋게 만든 개략 노선도 좌표다. 실제 위경도 선로 형상이 아니므로 OSM 위 선로로 전용하지 않았다. 철도 지도는 시간표에 기록된 정차역·통과점 순서와 `STATION_DB` 좌표로 중복 없는 인접 구간을 만든다.

## Phase 1 — 지도 데이터 계층

- `buildRailNetwork`: 열차별 정차·통과 순서에서 역과 인접 구간을 생성하고 노선·등급·운행 횟수를 집계한다.
- `trainGeoPath`: 선택 열차의 검증된 전체 운행 경로를 구성한다.
- `stationServices`, `stationTimetable`: 역별 운행 노선과 시간표를 기존 열차 데이터에서 역산한다.
- `estimatedTrainSnapshot`, `snapshotCoordinate`: 기존 `operationSnapshot`과 `operationPosition`을 재사용해 정차 시각 사이의 위치를 보간한다.

지도에 그리는 직선은 “역 좌표 연결 기반 개략 경로”이며 실제 게임 선로 형상으로 표시하지 않는다.

## Phase 2 — OpenStreetMap 지도

별도 지도 프레임워크를 추가하지 않고 Web Mercator 투영과 OSM 표준 타일을 사용한다. 타일 위에 SVG로 선로, 역, 선택 열차 경로, 시간표 기반 위치를 렌더링한다. 드래그, 휠/버튼 확대·축소, 전국 보기, 역 선택과 키보드 접근을 지원한다. OSM 타일을 끄거나 불러오지 못해도 철도 오버레이는 계속 동작한다. OSM 저작자 표시를 지도에 유지한다.

## Phase 3 — 화면과 기존 기능 연결

- 더보기 → 철도 노선도·열차 지도
- 철도 지도에서 역·열차번호·노선 검색, 노선 필터, 역 선택
- 역 상세에서 원본 ID/좌표/노선, 출발 열차 검색, 역 시간표, 지도 위치
- 조회 결과에서 선택 열차 지도
- 승차권/예매/환승 운행 정보의 큰 지도 연결
- 선택 열차 화면에서 전체 운행 경로, 시간표 기반 상태, 다음 정차역과 예상 시간
- 설정 → 지도 표시 설정에서 선로, 역명, 운행 중 열차, 선택 열차 강조, OSM 배경, 등급 필터 저장

모든 열차 위치 화면은 “시간표 기반 추정”과 “실시간 GPS 위치가 아님”을 표시한다.

## Phase 4 — 성능과 안정성

전체 토폴로지는 모델별로 한 번만 만들고 캐시한다. 현재 화면 밖의 선로와 역은 SVG에서 제외하며, 축척별로 역명 밀도를 줄인다. 전체 운행 중 열차 위치 계산은 사용자가 해당 설정을 켠 경우에만 수행한다. 앱 서비스 워커는 같은 출처의 앱과 NIMBY 데이터만 캐시하며 외부 OSM 타일을 오프라인 자산으로 저장하지 않는다.

- 반응형 폭: 320, 390, 600px
- 기존 설정 회귀: 검색·좌석·알림·화면·저장 초기화

## 남은 원본 데이터 제약

최신 공유 맵의 원본 선로 좌표를 읽을 수 없어 실제 게임 선형과 실시간 열차 좌표는 연결하지 않았다. 최신 원본에서 공식 선로 GeoJSON/좌표 배열과 안정적인 열차 위치 피드가 제공되면 현재 지도 데이터 계층에 별도 소스로 연결해야 한다. 과거 스냅샷은 자동 병합하지 않는다.
