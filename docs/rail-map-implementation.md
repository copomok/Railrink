# NIMBIRAIL TICKET 철도 지도 구현 보고

## 데이터와 책임 분리

지도 생성은 세 계층을 구분한다.

- 원본 기하: `Mysterious Enterprise.nimbyrails5`에서 추출한 70,281개 유효 선로점과 58,927개 명시적 참조 간선이다. 이 계층에는 단순화를 적용하지 않는다. 원본 SHA-256은 `9ef9cd8bec9a773e43830e11d07ea7a2f3b1206f4faa7b374e5e08adbbf61530`이다.
- 운행 가능 위상: 원본 레코드의 참조 간선과 좌표가 완전히 같은 정점만 연결한다. 가까운 끝점, 평면 교차, 나란한 복선은 연결 근거로 사용하지 않는다.
- 표시 기하: 전체 지도는 저장 파일에서 추출한 원본 선로 경로 12,980개를 그대로 표시한다. 전철선·일반선·고속선·삼각선·분기선·차량기지 연결선이 포함되며, 열차 경로 계산 결과와 무관하게 유지한다.

`tools/extract_nimbyrails5_map.py`가 저장 파일을 `data/nimbi_latest_map.js`로 추출하고 `tools/build_mainline_map.mjs`가 일반열차·KTX 노선만 `data/nimbi_mainline_map.js`로 구성한다. RailLink의 기본 지도와 선택 경로는 이 일반철도 데이터만 사용한다.

```sh
cd NIMBYRAILTABLE
python3 tools/extract_nimbyrails5_map.py \
  '../attachments/a5e1cb33-55b5-4569-84ed-8ed793039994/Mysterious Enterprise.nimbyrails5' \
  data/nimbi_latest_map.js
node tools/build_mainline_map.mjs
```

## 연결 판정

역 좌표 반경 2km 안의 원본 선로 연결요소를 후보로 찾되, 두 역에 공통인 연결요소가 정확히 하나일 때만 경로 탐색을 수행한다. 경로는 해당 원본 간선 안에서만 탐색하며 역간 직선거리 대비 2.5배 또는 18km를 넘는 우회는 거부한다. 끝점 스냅, 거리 기반 합성 간선, 점군 보간, 역간 직선 대체 경로는 생성하지 않는다.

현재 56개 일반철도 경로의 471개 역간 정의 가운데 168개는 원본 연결이 하나로 확인됐고 303개는 노선별 표시 선형을 대표 본선으로 사용한다. 합성 직선은 0개다. 대표 본선은 원본 선로에서 만든 곡선을 유지하며 역 구내의 복선·승강장 차이만 한 줄로 합친다. 과거 표시 추출기에서 역 구내 선로를 지나쳤다가 같은 지점으로 되돌아온 폐곡선은 원본 좌표 부분열만 남기는 고리 제거를 적용하며, 명시적 위상 구간은 수정하지 않는다.

분기선 합류와 일반선·고속선 전환은 열차의 노선 목록을 우선하는 역 그래프에서 탐색한다. 선언된 노선 사이에 짧은 일반철도 연결선이 필요한 경우 비용을 높여 보조 연결로만 사용한다. 전철 노선은 그래프에 들어오지 않으므로 일반열차 경로가 전철 선로로 우회하지 않는다.

선택 열차 경로도 같은 `segmentSources` 원본 식별자 열을 사용한다. 동일한 두 역 사이에 서로 다른 원본 식별자 열이 둘 이상 존재하면 하나를 임의 선택하지 않는다. 분기점에서 별도 연결 간선이 없는 평면 교차도 환승 가능한 연결로 보지 않는다.

## 표시와 지도 경계

원본 경로는 지도 타일과 별개인 하나의 SVG 월드 좌표 레이어에 그린다. 타일 단위로 기하를 자르거나 다시 연결하지 않으므로 확대 단계와 타일 경계가 위상을 바꾸지 않는다. 각 확인된 연속 경로는 하나의 SVG path로 만들고 `stroke-linecap: round`, `stroke-linejoin: round`를 사용한다. 선택 경로도 같은 방식으로 그려 곡선과 분기부가 확대·축소 시 끊겨 보이지 않게 한다.

기존 전체 화면 지도, 전체/선택 열차 모드, 검색, 확대·축소, 지도 설정과 하단 열차 정보창은 유지한다. 정보창에는 전체 확인, 부분 표시와 확인 불가 구간 수, 또는 경로 확인 불가 상태를 명시한다.

## 회귀 검증

Node 회귀 테스트는 다음을 검사한다.

- 원본 메타데이터와 저장 파일 버전, 합성 연결 0개
- 단절 구간에 직선이나 우회 경로를 만들지 않는지
- 가까운 병렬 선로 두 개 중 하나를 임의 선택하지 않는지
- 기하상 교차하지만 연결 간선이 없는 선로를 연결하지 않는지
- 검증된 곡선 경로와 거리 기준 열차 위치 보간
- ITX-청춘 2038, KTX-산천 8039, ITX-새마을 1142·1198의 연속 대표 본선 경로

모바일 Chromium 검증은 480×1040 화면에서 원본 선로 12,980개와 원본 연결·대표 본선 수, 합성 연결 0개, 네 문제 열차의 연속 경로, 하단 정보창, 지도 인스턴스 유지, 설정 저장, 320~720px 반응형 화면과 브라우저 오류 부재를 확인한다. 전체 1,907편을 별도 감사해 경로 1개, 누락 0개, 분할 0개를 강제한다.

## 남은 데이터 제약

저장 파일에는 360개의 노선 entity가 선언되어 있으며 현재 분석기는 그중 358개에서 노선명, 노선 코드, 순서가 있는 역 ID와 승강장 인접 선로점 ID를 읽었다. 일반철도, 전철, 입·출고 노선과 차량기지 역도 포함된다. 따라서 역 좌표만으로 추측하는 방식보다 강한 대응 근거가 생겼다. 다만 노선 entity가 역 사이의 모든 간선을 열거하지는 않으며, 현재 일반 열차 시간표에도 방향별 track ID 대응 정보가 없다. 서울·대전·울산과 복선·분기 구간에서 실제 분기 선택을 완전히 판별할 수 없는 이유다. 해석하지 못한 노선 레코드 2개와 명시적 참조 그래프의 단절도 남아 있다.

선로 표시 정책은 본선에 연결된 막다른 회차선, 복선에서 단선으로 갈라져 다른 선로에 합류하는 입체교차선, 운행 노선이 없는 회송 연결선을 포함한다. 승강장·대피선·건넘선은 열차 경로에서 세부 선로를 구분하지 않고 대표 본선 한 줄로 축약할 수 있다. 완전히 고립되고 노선 참조도 없는 선로는 제외 대상이다. 다만 현재 명시적 참조 그래프가 15,273개 연결요소로 나뉘고 노선 비참조 점이 20,269개라서, 이들을 즉시 폐선으로 삭제하면 파서가 놓친 정상 선로도 사라진다. 고립 선로 필터는 파서 누락을 구분한 뒤 적용하며 그 전까지 운영 원본 선로를 유지한다.

## 검증 경로 시범 데이터

운영 지도는 471개 역간 정의 중 명시적 참조로 확인된 168개 구간을 그대로 사용하고 나머지 303개는 원본 선로에서 만든 노선별 표시 선형을 대표 본선으로 연결한다. 대표 본선은 역 구내의 승강장·대피선·건넘선 차이를 한 줄로 합친다. 차량기지 이름이 있는 구간은 본선과 별도 분류한다.

남안양–수원–오산–평택은 등급별 복선 차이를 생략하고 경부선 대표 본선 하나를 사용한다. 남안양–수원 시범 형상은 6개 주요 좌표로 곡선을 유지하며, 이 구간을 연속 이용하는 327개 일반열차 운행이 같은 segment를 양방향으로 재사용한다.

신탄진–회덕역/대전차량기지는 본선 시범에서 제외하고 회송·차량기지 연결선으로 분류했다. 원본 지도에는 유지하지만 고속선이나 일반 본선 운행 경로의 대표 구간으로 사용하지 않는다.

서울–남금호–청량리는 전철 원본 선로를 직접 선택하지 않고 `경원선` 일반철도 표시 선형을 하나의 도심 대표 본선으로 사용한다. 서울과 다른 복잡한 역 구내에서도 같은 역의 앞뒤 구간 끝점을 하나의 대표점으로 이어 끊김을 제거한다. 다른 노선으로 빠지는 후보가 함께 있으면 정차역 사이에 중간 분기역이 없는 직접 본선을 우선한다. 북한 구간의 `은산`과 `은산읍`처럼 동일 위치의 노선별 명칭은 해당 운행 노선 안에서만 통합한다.
